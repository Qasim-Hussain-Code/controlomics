# Development changes

## 0.3.0.dev0, 2026-10-06

Extended the local workflow with inspectable operation and design rules, literal description drafting, multiple claims, researcher-created and editable unreviewed candidates, direct source-review forms, and explicit evidence re-review with superseded snapshot hashes. Repeated retrieval preserves the earlier identity prerequisite of existing reviews. Hosted responses must target one known claim.

Added typed evaluation datasets, offline baseline runs, unassessed annotation templates, partition checks, denominator-aware metrics, nominal annotation agreement, and an Evaluation tab. Thirteen workflow schema exports supplement the unchanged ten core exports. Development fixtures are explicit; scientific control-quality and evidence accuracy are unavailable without assessed annotations.

No runtime dependencies were added. Independent experts, biological validation, hosted-model evaluation, specialist execution, license selection, and public publication remain pending. Package and interface checks establish a local software milestone, not completion of the research objective.

Final review restricted the numeric adapter to supported technical positive and negative references, preventing unrelated calculations being recorded as design challenges. CLI description reads reject oversized multibyte text without truncation, and JSON context and ledger reads are bounded.

## 0.2.0.dev0, 2026-10-06

Implemented an operational local research workflow: explicit claim intake, a conservative method baseline, a Messages-compatible model interface, two literature adapters, identifier consolidation, exact-request privacy review, human statement/context review, reports, fixed numeric execution packages, result import, a development benchmark, and a loopback-only interface.

Privacy changes include destination checks, pinned public connections with hostname-verified TLS, exact field-to-request binding, disabled redirects, redacted errors, no project persistence, and credential exclusion from exports. The local interface checks host, origin, and session token. Fixed numeric scripts check package hashes before importing their helper module and calculate input hashes from the same byte snapshot used for computation.

The project format and ontology remain 0.1.0. Existing Stage 1 projects are readable. Package version is a development version, not a public release. There is no validated biological domain, expert-grounded benchmark, hosted-model evaluation, or demonstrated agent generalization. License selection and public publication remain pending.

## 0.1.0.dev0, 2026-10-05

Established scientific documentation, nine core schemas, a versioned ontology, local project validation, JSON Schema export, two hypothetical examples, and 37 software checks. No external retrieval or execution was implemented at that milestone.
