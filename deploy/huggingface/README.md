# Controlomics

This Space runs the Controlomics hosted prototype from its public source at https://github.com/Qasim-Hussain-Code/controlomics. The build downloads the `main` branch and installs the exact cloud dependencies. Rebuilding the Space picks up later source; a running Space does not update itself.

Open the workspace at its direct address, https://qasimhussain-controlomics.hf.space. The application refuses to be framed, so the panel on this Space page stays blank.

On first use the interface asks for consent to temporary cloud processing. The application keeps no project database or saved uploads, so export your work before closing. Hugging Face collects connection and operational metadata under its own privacy policy. A free Space sleeps when unused, and a restart ends open sessions.

The hosting guide at https://github.com/Qasim-Hussain-Code/controlomics/blob/main/docs/HOSTING.md describes the configuration and its limits.
