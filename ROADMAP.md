## Delivered slice

Hypothetical transcriptomics and microscopy examples exercise intake, primary control classes, audit, reporting, and synthetic reference calculations. Retrieval preserves aliases without converting identity into statement support. Human review records support, contradiction, incomplete context, and limitations. Hosted proposals remain separately reviewable.

Six explicit design scenarios compare the two-reference baseline with operation rules. Their recommendation sheets remain UNASSESSED. Development expected finding codes test software behavior and do not establish scientific generalization. They are neither the domain boundaries of the representation nor an independent benchmark. See [the evaluation protocol](docs/EVALUATION.md).

## Next research work

Version 0.6.1.dev0 adds staged single-file exports with supported access restrictions and checks conflicting sidecar paths before writes or provider requests. Whole-project imports preserve runner-hash and single-result consistency. New isolated browser checks cover evaluation invalidation, pending-input protection, and interrupted or expired local sessions. The numerical sources and frozen findings remain unchanged.

Use [the proposed independent-study protocol](docs/INDEPENDENT_VALIDATION_PROTOCOL.md) to build an independently sourced benchmark with verified identities, expert annotations, adjudication, negative cases, domain-held-out partitions, and explicit abstentions. The local readiness audit distinguishes record completeness from verified scientific independence. The local tools implement stated denominators and missing-annotation handling; the proposed sampling and uncertainty design still need to be adopted for the actual cases before that study begins.

Evaluate configured reasoning providers against method checklists and retrieval-only baselines. Separate numerical adapter behavior from agent performance. Include retrieval, representation, review, and execution ablations. Extend execution when independently specified scientific expectations justify an adapter.

License selection and public release remain owner decisions. Public hosting, external expert recruitment, and manuscript Results require their own completed work and authorization. No dates or outcomes are invented.
